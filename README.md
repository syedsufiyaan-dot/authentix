## 🌟 About AuthentiX

**AuthentiX** is a portable **mobile device authenticity and diagnostic analyzer** designed to help users understand the actual condition of a smartphone before purchasing it.

The system combines **Raspberry Pi, sensors, and Python-based analysis** to evaluate important aspects of a mobile device.

Instead of relying only on the external appearance of a phone, AuthentiX focuses on its **internal health and performance indicators**.

### 🎯 Core Goal

> **"Don't just check the phone. Know the phone."**

AuthentiX aims to provide an overall mobile health analysis covering:

- 🔋 Battery Health
- ⚡ Charging Performance
- 💾 Storage Condition
- 📶 Connectivity
- 🔧 Hardware Diagnostics
- 🛡️ Authenticity Verification
- 📊 Overall Device Health
- ⭐ Trust Score
